# GraphQL Documentation with Hugo Book

This is a demo site showcasing GraphQL schema documentation generated by
[GraphQL-Markdown](https://graphql-markdown.github.io/) using the
[Hugo Book theme](https://github.com/alex-shpak/hugo-book).

## Getting Started

1. **Generate GraphQL docs**:
   ```bash
   npm run generate
   ```
   This creates GraphQL documentation in `content/graphql/`.

2. **Preview locally**:
   ```bash
   npm run dev
   ```
   Opens the site at `http://localhost:1313`.

3. **Build for production**:
   ```bash
   npm run build
   ```
   Creates static site in `public/`.

## Features

- 📖 Clean, book-like documentation theme
- 🔍 Full-text search across all pages
- 🌓 Auto dark/light mode switching
- 📱 Mobile-friendly responsive design
- ⚡ Lightning-fast static site generation

## What's Inside

Navigate to the **GraphQL** section in the sidebar to view the auto-generated schema documentation.
All types, queries, mutations, and subscriptions are documented with descriptions and field details.
